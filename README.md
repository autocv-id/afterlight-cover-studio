AFTERLIGHT Cover Studio — an offline web app that turns your own photos and a caption into GTA-style multi-panel cover art, exported as a PNG in the three common post sizes (1080 × 1080, 1080 × 1350, 1920 × 1080). Eight panel layouts, six colour grades, per-panel crop and positioning, a pop-out hero cut-out, a character-stat card, and the full poster furniture set: press quote, ticket stub, gold seal, barcode, billing footer and heat pill. Everything runs in the browser from the app's own files — no network, no uploads.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
